# Apex Trading Agent

Apex is a deterministic Binance USDT perpetual-futures **opportunity discovery and trade-analysis engine**.

It scans active futures markets, evaluates multi-timeframe structure, routes compatible strategies, searches for usable entries, defines structural invalidation, projects realistic targets, and explains why a setup is actionable, developing, late, rejected, or unavailable.

> Apex is an analysis tool, not an execution bot. It does not place orders, manage wallets, recommend leverage, operate paper/testnet accounts, or guarantee profitable trades.
