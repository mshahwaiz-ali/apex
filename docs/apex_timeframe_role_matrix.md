# Apex Timeframe Role Matrix

| Timeframe | Role | Authority | Must not do |
|---|---|---|---|
| 4h | Macro | Regime and decisive structural opposition | Supply micro entry timing |
| 1h | Intermediate | Direction and volatility context | Block every scalp on mild disagreement |
| 30m | Intraday | Nearby structure and major obstacles | Replace 4h macro state |
| 15m | Setup | Setup construction and swing context | Treat active patterns as complete |
| 5m | Entry | Pullback, retest, breakout, and execution quality | Manufacture macro direction |
| 3m | Refinement | Trigger refinement | Bypass invalid setup geometry |
| 1m | Timing | Micro trigger only | Independently authorize a trade |

Configured indicator profiles differ by role. All periods and thresholds remain
rank/gate rules until validated out of sample.
